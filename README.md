# sadmanshkib.github.io

Personal portfolio website of **Shkib Sadman** — Software Engineering student at Yangzhou
University working on applied AI and LLM systems engineering.

Live at **https://sadmanshkib.github.io**

## Built with

Hand-written HTML, CSS and JavaScript. No frameworks, no build step, no dependencies —
the whole site is static and served directly by GitHub Pages.

```
index.html            single-page site (hero, about, work, skills, awards,
                      credentials & verification, experience, contact)
404.html              custom not-found page
assets/css/styles.css all styling (dark theme, responsive, reduced-motion & print support)
assets/js/main.js     nav state, mobile menu, scroll reveal, active-section highlighting
assets/img/           headshot (jpg + webp), square avatar, favicon, social cover
assets/Sadman_Shkib_CV.pdf   downloadable CV (two pages, A4)
```

## Local preview

```bash
python -m http.server 8000
# then open http://localhost:8000
```

## Content sources

All content is drawn from the author's own CV and application material — no invented
projects, metrics or credentials. Where work is applied systems engineering over
pretrained models, it is described as such.

The **Credentials** section lists every award and appointment with its issuing body, the date
printed on the document and a status marker (on file / awaiting document). Certificate scans are
held privately and supplied on request rather than published, because they carry a student number,
room numbers and the names of teammates. Team awards are labelled as team awards and performance
commendations are not presented as ranked prizes.
